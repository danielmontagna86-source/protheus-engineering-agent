# Jornada do desenvolvedor

1. Execute Doctor e confirme perfil, encoding e capacidades disponíveis.
2. Indexe o workspace e trate chamadas não resolvidas como incerteza.
3. Revise o fonte ativo; corrija achados no editor e acompanhe Problemas.
4. Revise o escopo Git correto e exporte o JSON/SARIF.
5. Registre decisões no Journal; promova apenas conteúdo revisado para Project Memory.
6. Se houver adapter real, prepare o build, confira comando/ambiente e aprove nominalmente antes de executar.

Saída: mudança + evidência reproduzível. Compilação só é verificada quando o envelope contém compilador, exit code zero e artefato com SHA-256.
