1. Run locked install, validation, smoke, benchmark, and packaging from a clean checkout.
2. Install the real VSIX in isolated minimum/current VS Code profiles and repeat with TDS.
3. Test multi-root, Git scopes, CP1252/LF, cancellation, timeout, malformed inputs, and no-network/no-Docker operation.
4. Perform keyboard, focus, screen-reader, high-contrast, zoom, and pt-BR/en checks.
5. Keep fixture, simulation, contract, and live evidence distinct. Synthetic adapters never prove AppServer or database compatibility.

Outcome: exact-commit/hash gate evidence and NO-GO for every missing mandatory proof.
