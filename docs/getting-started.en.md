# Get started in five minutes

1. Install the VSIX and open Engineering Center in the Activity Bar.
2. Run **Protheus Agent: Open Offline Sample Workspace**.
3. Run **Doctor**, **Index Workspace**, and **Review Active ADVPL/TLPP File**.
4. Inspect native **Problems** diagnostics and the JSON evidence in the Output channel.
5. In a Git-backed project, run **Review Git Changes** to produce change-set evidence.

This path needs no Docker, Protheus, database, Hermes, model, or network. It is deterministic pre-review, not compiler proof.

Journal entries carry attribution. Promote them to structured Project Memory only after reviewing the exact preview and before/after hashes. Import TDN/Dictionary snapshots only when origin and license or owner authorization are declared. A supervised build remains `BUILD_UNAVAILABLE` until a trusted host supplies a real adapter and lawful environment.

Continue with `docs/workflows/en/`, `schemas/pea-config.schema.json`, and `docs/limitations.md`.
