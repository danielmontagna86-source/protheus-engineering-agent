# Support

This project is an independent community alpha and is not an official TOTVS support channel.

- Use GitHub Issues for reproducible defects and feature proposals.
- Use the security process in [SECURITY.md](SECURITY.md) for vulnerabilities or sensitive reports.
- Include the extension version, VS Code version, operating system, minimal reproduction and sanitized output.
- Never attach credentials, customer sources, RPO contents, database data, environment files or unsanitized production logs.

Compilation, AppServer, RPO, Oracle, TDN and Dictionary adapters are not supported in the current alpha unless the release notes explicitly say otherwise.
